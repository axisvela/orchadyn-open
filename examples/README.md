# Examples

Request bodies for the ORCHADYN Planning API.

- [`procurement-plan.json`](procurement-plan.json): budget and region
  constraints with an authority grant and delegation contract.
- [`scheduling-plan.json`](scheduling-plan.json): deadline, availability, and
  SLA constraints, scheduling metadata on catalog capabilities, and goal
  decomposition through `dependsOn`.

For lifecycle, evidence, and execution-tracking flows see the
[Go SDK guide](../docs/sdk-go.md) and the [quickstart](../docs/quickstart.md).
